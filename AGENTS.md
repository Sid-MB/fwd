
## Coding Principles

Break code down into modular, reusable components. Reuse code as much as possible; there should be no redundant parts or duplicated methods anywhere, and if we're editing the same thing in multiple places it may be better in a single central location. Create classes and conform to them as necessary for abstraction, but do not have too many layers of abstraction and have no useless wrapper classes.

Add docstrings to classes and methods, and keep the [user docs](./docs/README.md), [developer docs](./dev-docs/README.md), [README](./README.md), and [SKILL.md](./SKILL.md) up to date.
