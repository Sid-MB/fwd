# Generated manual pages

The `.1` files in this directory are autogenerated. Do not edit them directly.

Their command structure and option text come from `src/fwd/cli.py`; conventional authored sections and roff generation live in `tools/generate_man_pages.py`. After changing either source, regenerate and validate every page locally:

```sh
uv run python tools/generate_man_pages.py
uv run python tools/generate_man_pages.py --watch
mandoc -T lint man/*.1
```

The generated `.1` files are ignored by Git. Hatch regenerates them for every wheel and source-distribution build, so PyPI releases and installs directly from Git carry pages matching the exact source being packaged. The source distribution includes the generator and build hook, allowing downstream rebuilds to reproduce the pages.
