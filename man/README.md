# Generated manual pages

The `.1` files in this directory are autogenerated. Do not edit them directly.

Their command structure and option text come from `src/fwd/cli.py`; conventional authored sections and roff generation live in `tools/generate_man_pages.py`. After changing either source, regenerate and validate every page:

```sh
uv run python tools/generate_man_pages.py
uv run python tools/generate_man_pages.py --check
mandoc -T lint man/*.1
```

Generated pages are committed so releases and operating-system packagers can consume them without executing project code during packaging.
